常见问题

市场材料是已经上架了吗？

没有。所有平台的市场材料都是 NOT-SUBMITTED 占位骨架，端点用保留域、凭据只有环境变量名。这个项目不把占位说成已上架——`market-preflight` 会告诉你离真实提交还差什么。

和 Composio / OpenConnector 有什么区别？

方向相反：它们把现成 SaaS 的 API 接给 Agent 用；本工具把你自己的应用发布成 MCP 服务并接入 Agent 平台，吸收的是各平台配置格式与上架审核的差异。

需要公网服务器吗？

本地配置生成不需要。市场上架普遍要求公网 HTTPS MCP Server——唯一的例外是 ZCode 插件市场：插件可自带 stdio MCP，不强制公网端点。逐平台条件见 market-preflight。

支持哪些平台？

当前 7 个：WorkBuddy、千问办公、豆包工作、ChatGPT/Codex、Cursor、Claude Desktop、ZCode。钉钉（MCP 广场）、飞书（aily MCP 市场）、百度 Comate / 文心智能体已列入下批规划。

连接器本体在仓库里吗？

不在。stdio 连接器是 OpenBot 工作区的独立实现；本仓库负责配置生成、市场材料与体检。可用 --connector-path 指向任意 MCP stdio 可执行文件。

如何贡献？

读 CONTRIBUTING.md 的十条纪律：闸门全绿、EXPECTED_CASES 同步、变异验证、政策事实必须带证据等级。CI 会在生成产物与注册表不同步时拒绝。
